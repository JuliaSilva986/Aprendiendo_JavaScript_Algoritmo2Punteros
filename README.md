# 👥 Algoritmo de los Dos Punteros en JavaScript

Mini proyecto desarrollado en JavaScript como parte del módulo de **Algoritmos de los Dos Punteros de DEV.F**.

## 📌 Descripción

El programa permite registrar una lista de invitados y encontrar el primer par de nombres consecutivos que comiencen con la misma letra, utilizando la técnica de los dos punteros.

## ⚙️ Funcionalidades

- Registrar invitados mediante `prompt()`.
- Almacenar los nombres en un arreglo.
- Ordenar los invitados alfabéticamente.
- Comparar las iniciales de nombres consecutivos utilizando dos punteros.
- Mostrar la primera pareja encontrada o indicar si no existe ninguna.

## 💻 Tecnologías

- JavaScript
- HTML5

## 🎯 Objetivo

Practicar el algoritmo de los dos punteros para realizar búsquedas eficientes en arreglos ordenados, evitando comparaciones innecesarias.

**Complejidad temporal:** O(n) para la búsqueda y O(n log n) para el proceso completo, considerando el ordenamiento previo.
